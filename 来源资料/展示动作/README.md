# 展示

- `展示.tscn`：原方向、透明背景、可直接实例化。
- `展示_镜像.tscn`：镜像方向、透明背景、轴心已同步修正。
- `展示_SpriteFrames.tres`：只包含“展示”这一个动作的 SpriteFrames。
- `透明预览/展示.webp`：可独立播放的原方向透明动画；该子目录已设置为不让 Godot 导入。
- `透明预览/展示_镜像.webp`：可独立播放的镜像透明动画。
- `逐帧/`：90 张完整 RGBA PNG，是 Godot 动画的实际帧源。
- `动画信息.json`：原始帧序、画布、轴心和来源信息。

当前预览速度为 83 毫秒/帧；原始精确时间轴未包含在源 Bundle 中。
